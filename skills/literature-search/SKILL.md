# Literature Search

Search to answer a defined question, not merely to collect citations.

1. Translate the question into key concepts, synonyms, method names, and exclusion terms.
2. Search more than one relevant source when available (for example, scholarly indexes, publisher sites, arXiv, conference proceedings, standards, or official documentation).
3. Prefer primary papers, original datasets, standards, and official project documentation. Use surveys to discover relevant primary work.
4. Record query, source, date searched, inclusion/exclusion reason, DOI/URL, publication status, and accessible version.
5. Deduplicate by DOI/title and verify author, title, venue, year, and URL against the source record.
6. Follow references and citations selectively until additional searching yields diminishing returns.
7. Flag paywalls, inaccessible papers, retracted work, preprints, and uncertain metadata.

Return a traceable search log and annotated bibliography. Never fabricate references or fill missing metadata from model memory. Do not describe an uninspected paper as supporting a claim.
